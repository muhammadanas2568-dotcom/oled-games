วิธีเอาเกมขึ้นออนไลน์ให้ Get Games ดาวน์โหลด
1) สร้าง GitHub repo สาธารณะ (เช่น oled-games) แล้วอัปโหลดไฟล์ index.txt และไฟล์ .ogs ทั้งหมดในโฟลเดอร์นี้
2) ในสเก็ตช์ แก้ GAME_BASE_URL เป็น
   https://raw.githubusercontent.com/ชื่อบัญชี/oled-games/main/
   (ต้องลงท้ายด้วย /)  หรือจะใช้เซิร์ฟเวอร์ในบ้านก็ได้ เช่น http://192.168.1.50:8000/
   (รันบนคอมด้วย  python3 -m http.server 8000  ในโฟลเดอร์นี้)
3) เพิ่มเกมใหม่ = เพิ่มไฟล์ .ogs แล้วเพิ่มบรรทัด  ชื่อเกม|ชื่อไฟล์.ogs  ใน index.txt
   ชื่อเกมไม่เกิน 12 ตัวอักษร, ชื่อไฟล์ใช้ a-z 0-9 _ เท่านั้น, ขนาดไฟล์ไม่เกิน 4 KB

ภาษาเกม (OGS) แบบย่อ  : ดูตัวอย่างในไฟล์ .ogs
  ตัวแปร a-z (ตัวเลขเต็ม) / อาร์เรย์ m[0..63] / btn (กดเมื่อกี้) held (กำลังกดอยู่) tick score
  ฟังก์ชัน rnd(n) abs(x) min(a,b) max(a,b)   ตัวดำเนินการ + - * / % < > <= >= == != && || !
  คำสั่ง if..else..end  while..end  cls pix line rect fill circ disc text num spr col size over
  ส่วนที่ต้องมี: init (รันครั้งเดียว) และ frame (รันทุกเฟรม)  บรรทัดบนสุด: title ชื่อ / fps จำนวน
