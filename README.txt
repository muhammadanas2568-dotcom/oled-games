9 original CHIP-8 games (none duplicate the home-page games). Keys: 4 = left, 6 = right, 5 = button.
 Munch  - Pac-Man style: auto-walk, L/R turn, eat all dots, avoid the ghost
 Bounce - keep the ball up with the paddle
 Dodge  - avoid falling blocks
 Catch  - catch the falling dots
 Whack  - whack-a-mole: left / button / right = left / middle / right hole, 3 lives
 Pong   - L/R = paddle up/down, beat the CPU, first to 20
 Simon  - memory: repeat the light sequence (left / button / right)
 Lander - L/R move, button = thrust, land softly on the pad
 Racer  - L/R change lane, dodge the cars
