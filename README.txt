OLED Arcade CHIP-8 ROM Pack

Contains 12 original minimal CHIP-8 homebrew movement demos. Pac-Man Mini is an original Pac-Man-inspired demo, not an official Pac-Man ROM.

Copy the .ch8 files and index.txt to the same location used by your Get Games index server. The firmware index parser expects title|filename|optional key mapping.

These ROMs have not been tested on the target ESP8266 emulator. Some interpreters may need key mapping or ROM adjustments.
